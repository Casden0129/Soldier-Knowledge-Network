# Security Policy

## Public repository boundary

This repository is public. Do not place sensitive or controlled information in code, JSON, issues, pull requests, screenshots, logs, or comments.

Never submit:

- CAC certificates, PINs, passwords, tokens, or credentials
- Social Security numbers or DoD identification numbers
- Personnel, medical, financial, or legal records
- Orders, rosters, manifests, or internal contact lists
- Controlled Unclassified Information
- Operational, intelligence, force-protection, vulnerability, or security-system information
- Internal-only documents or screenshots

## Reporting a security concern

Do not open a public issue containing exploit details or sensitive evidence. Contact the repository owner privately through an established non-government personal channel. For an official Army or DoD system, use that organization’s authorized reporting and help-desk process; SKN does not administer external systems.

## Scope

SKN is a static navigation website. It does not authenticate users, store user accounts, process CAC data, or operate Army systems.
