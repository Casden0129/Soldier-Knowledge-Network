# Editorial Standards

1. Write for a first-time user in plain language.
2. Define acronyms in the full name field.
3. Describe what the user can accomplish, not marketing claims.
4. Prefer the responsible official source.
5. Clearly classify non-government destinations.
6. Do not imply Army, DoD, command, unit, or employer endorsement.
7. Separate fact from advice and identify the authoritative source.
8. Use exact publication identifiers and paragraphs in future study content.
9. Record review dates honestly; do not mark an inaccessible system verified solely because an automated check passed.
10. Correct errors transparently through the changelog or update log when significant.
