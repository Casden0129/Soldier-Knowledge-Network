# Resource Verification Standard

A resource is manually verified when an editor has:

- Confirmed the responsible owner from an official source
- Reviewed the destination domain
- Opened the public landing page when technically possible
- Recorded authentication and network limitations
- Compared the SKN description with the official purpose
- Checked common and legacy names
- Checked whether the service was replaced, retired, or redirected
- Entered the actual review date

Automated link checks are only indicators. CAC-protected, Army-network, VPN, bot-blocked, or authentication-redirecting systems require human judgment.

## Approved statuses

- `active`
- `temporarily-unavailable`
- `under-review`
- `redirected`
- `replaced`
- `retired`
