# Contributing to SKN

Thank you for helping make Army information easier to find.

## Before submitting

1. Search existing resources and issues.
2. Use the responsible official organization as the primary source whenever possible.
3. Confirm the destination domain and describe the resource in plain language.
4. Do not copy controlled documents or submit sensitive information.

## Prohibited submissions

Never submit CAC data, passwords, authentication tokens, Social Security numbers, DoD ID numbers, medical information, personnel records, orders, rosters, CUI, internal-only documents, vulnerability details in a public issue, or operational information.

## Resource changes

A resource entry should identify its official owner, audiences, source type, tasks, access conditions, network requirement, status, verification date, keywords, legacy names, and HTTPS destination.

Run:

```bash
python scripts/validate_data.py
```

## Pull requests

- Use a focused branch and descriptive title.
- Explain the user need and official source supporting the change.
- Keep unrelated formatting changes out of the pull request.
- Confirm that the site works on mobile and keyboard navigation remains usable.
- Wait for review before merging to `main`.

## Editorial style

Use plain, neutral language. Define acronyms. Do not imply endorsement, guarantee access, or present SKN as an official authority.
